# Lore Writing

Use `dm-hero-authoring` for campaign resolution, proposals, approval, writes, and canon safety.

Store reusable background as Lore entities, using a linked Markdown document for long-form treatment. Keep facts searchable, related, and explicit about canon status.

1. Search Lore and related NPCs, Factions, Locations, Quests, Dialogues, and Manuscript sections.
2. Separate verified facts, interpretation, rumor, contradiction, and invention.
3. Propose subject, evidence, additions, knowers/disputants, consequences, tags, folder, relations, and optional document.
4. After approval, create or update the record and persist explicit links.
5. Re-read connected material and report conflicts, unresolved references, and downstream effects.

Use one Lore entity per independently reusable subject. Extend a matching subject; create a distinct record for genuinely different or intentionally conflicting accounts. Report IDs/UIDs, canon status, links, conflicts, and pending additions.
